Políticas de Privacidade

A Power Play E-Sport respeita a privacidade dos seus utilizadores. As informações recolhidas neste site servem apenas para comunicação, gestão de eventos, academias e contacto com os membros.

Não partilhamos dados pessoais com terceiros sem consentimento, excepto quando exigido por lei. Dados como nome, contacto e interações podem ser usados para melhorar os nossos serviços.

Ao utilizar este site, o utilizador concorda com estas políticas. Para mais informações, entre em contacto connosco pelos canais oficiais.
